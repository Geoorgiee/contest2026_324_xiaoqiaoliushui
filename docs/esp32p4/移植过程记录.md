### 关键代码片段

#### 1. 启动入口 (`esp32p4_start.c`)

```c
/* ESP32-P4 Memory Layout:
 *   HP Core SRAM: 768 KB at 0x4ff00000
 *   PSRAM:        up to 32 MB at 0x48000000
 *   Flash:        up to 16 MB at 0x42000000
 */

extern uint8_t _ebss[];
#define HEAP_BASE      ((uintptr_t)_ebss + CONFIG_IDLETHREAD_STACKSIZE)
```

C 入口点 `__espressif_start` 负责：
1. 初始化 PSRAM 控制器
2. 配置 PLL 时钟（400 MHz CPU）
3. 调用 `nx_start()` 启动 NuttX 内核

#### 2. PLIC 中断控制器 (`esp32p4_irq.c`)

```c
/* The ESP32-P4 uses a standard RISC-V PLIC (Platform-Level Interrupt
 * Controller) for external interrupt routing. The PLIC sits between
 * peripheral interrupt sources and the RISC-V Hart interrupt lines.
 *
 * ESP32-P4 has 64 external interrupt sources routed through the PLIC.
 * The PLIC supports priority-based preemption (7 priority levels).
 *
 * RISC-V external interrupt is connected to MIP.MEIP (bit 11 of the
 * mcause CSR for external interrupt = 11).
 */
```

实现了标准 RISC-V PLIC claim/complete 协议：
- `up_irqinitialize()` - 初始化 PLIC，禁用所有中断，设置阈值为 0
- `up_enable_irq(irq)` - 设置优先级并使能指定中断
- `up_disable_irq(irq)` - 禁用指定中断
- `riscv_dispatch_irq()` - 中断分发，读取 claim 寄存器获取中断号
- `irq_attach(irq, handler, arg)` - 注册中断处理函数到 `g_irqvector[]`

#### 3. 系统滴答定时器 (`esp32p4_timerisr.c`)

```c
/* ESP32-P4 has HP Timer Group 0 with two 54-bit timers (Timer 0 and
 * Timer 1). Each timer is driven by the APB clock (80 MHz by default)
 * with a 16-bit programmable prescaler (divider range 2-65536).
 *
 * For system tick, we use HP Timer Group 0, Timer 0.
 * Prescaler = 80, so timer clock = 80 MHz / 80 = 1 MHz (1 us per tick)
 * Auto-reload period = CONFIG_USEC_PER_TICK
 */
```

定时器配置：
- 使用 HP Timer Group 0, Timer 0
- 预分频器 = 80，得到 1 MHz 时钟（1 us/tick）
- 自动重载周期 = `CONFIG_USEC_PER_TICK`

#### 4. 堆内存分配 (`esp32p4_allocateheap.c`)

双区域内存策略：
- 当 PSRAM 启用时：PSRAM（最大 32 MB）作为主堆，HP SRAM（768 KB）作为辅助区域
- 当 PSRAM 未启用时：HP SRAM（768 KB）作为主堆

### 关键代码片段

#### 1. defconfig 关键配置

```
CONFIG_ARCH="risc-v"
CONFIG_ARCH_BOARD_CUSTOM_DIR="../vendor_esp32p4/boards/risc-v/esp32p4/esp32p4-evb"
CONFIG_ARCH_CHIP_CUSTOM_DIR="../vendor_esp32p4/chips/esp32p4"
CONFIG_ESP32P4_UART0=y
CONFIG_ESP32P4_GPIO=y
CONFIG_ESP32P4_TIMER=y
CONFIG_ESP32P4_PSRAM=y
CONFIG_ESP32P4_PSRAM_SIZE=32
CONFIG_ESP32P4_PSRAM_MODE_OPI=y
CONFIG_ESP32P4_FLASH_SIZE=16
CONFIG_RAM_START=0x4FF00000
CONFIG_RAM_SIZE=786432
CONFIG_UART0_SERIAL_CONSOLE=y
CONFIG_MM_REGIONS=2
```

#### 2. 启动序列

标准 NuttX 启动流程：
```
__start (esp_head.S)
  -> __espressif_start (esp32p4_start.c)
    -> nx_start()
      -> board_early_initialize() (esp32p4_boot.c)
        -> esp32p4_board_initialize()
          -> esp32p4_board_periph_init()   // IO MUX, 电源域
          -> esp32p4_board_console_init()  // 控制台验证
          -> esp32p4_board_gpio_init()     // LED/按键 GPIO
      -> board_late_initialize()
        -> esp32p4_bringup()               // 注册设备驱动
          -> esp32p4_gpio_init()           // GPIO 驱动注册
```

#### 3. 链接脚本内存布局

```
MEMORY
{
    flash (rx)  : ORIGIN = 0x42000000, LENGTH = 16M
    sram  (rwx) : ORIGIN = 0x4FF00000, LENGTH = 768K
}
```

- Flash（0x42000000，16MB）：存放 .text 和 .rodata（XIP 执行）
- SRAM（0x4FF00000，768KB）：存放 .data 和 .bss
- PSRAM 堆由芯片层 `esp32p4_allocateheap.c` 动态管理

## 设计决策

### 芯片层

1. **UART 驱动**：使用 NuttX `uart_dev_s`/`uart_ops_s` 框架，支持完整的中断驱动 TX/RX，而非仅轮询模式
2. **中断控制器**：使用标准 RISC-V PLIC claim/complete 协议，维护 `g_irqvector[]` 处理函数表
3. **定时器驱动**：配置 HP Timer Group 0，预分频器=80（从 80 MHz APB 得到 1 MHz），自动重载精确匹配 `CONFIG_USEC_PER_TICK` 周期
4. **堆分配器**：支持双区域内存——PSRAM 作为主堆（大容量）+ SRAM 作为辅助堆（高速）

### 板级层

1. **自定义目录集成**：defconfig 使用 `CONFIG_ARCH_BOARD_CUSTOM_DIR` 和 `CONFIG_ARCH_CHIP_CUSTOM_DIR` 指向 vendor 目录
2. **启动分离**：`esp32p4_boot.c` 提供调度器启动前的早期初始化（GPIO、IO MUX、电源域），`esp32p4_bringup.c` 在调度器运行后注册设备驱动
3. **驱动注册**：`esp32p4_bringup()` 在 `CONFIG_ESP32P4_GPIO` 启用时主动调用 `esp32p4_gpio_init()`，SPI/I2C 注释为后续扩展预留
4. **内存映射一致**：链接脚本与芯片层内存映射匹配——768KB HP SRAM 在 0x4FF00000，16MB Flash 在 0x42000000
