**测试方法：**

2. 烧录到开发板
3. 连接串口终端

**测试命令：**
```bash
# 配置
./tools/configure.sh esp32p4-evb:default

# 编译
make -j$(nproc)

# 烧录（使用 esptool）
esptool.py --chip esp32p4 -p /dev/ttyUSB0 -b 921600 \
  --before default_reset --after hard_reset \
  write_flash 0x0 build/nuttx.bin

# 串口监控
minicom -D /dev/ttyUSB0 -b 115200
```
